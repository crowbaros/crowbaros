# Branding

The CrowbarOS identity is approved and carries over unchanged: the name, the
Rookslash crow, the Nullkeel palette, Manrope, and IBM Plex Mono.

| Path | Contents |
| --- | --- |
| [`crowbaros-brand-kit/`](crowbaros-brand-kit/) | The approved kit: logos, crow artwork, wallpapers, tokens, fonts, the brand guide, and the desktop studies |
| `CrowbarOS-brand-kit.zip` | The same kit as one archive |
| `round-01/`, `round-02-dark/`, `round-03-cyan-crow/` | The concept rounds that led to the kit |
| `history/` | The kit under its earlier name |
| `check_domains.py`, `naming-domain-checks.json` | The naming and domain checks |

The kit is a released artifact with a manifest of file hashes, so its files are
left as approved. Its notes name Fedora, Hyprland, and five default apps as the
product. That part is superseded by the [vision](../archive/substrate-vision/VISION.md). The desktop
studies in `mockups/` are visual references, not a specification.

For how the identity is applied in native interfaces, see
[`DESIGN.md`](../../DESIGN.md).
